## Decisions

1. Proof split: AC3-UI-02 and AC3-UI-04 claimed by pytest markers; AC3-UI-01, -03, -05 and V02-UI-* are `verification = "frontend"` with path-checked evidence. `--stage M6` must report `proven: 2`, not `0`.
2. vitest fixtures are typed as `components["schemas"][...]` so `npm run check` breaks on schema drift, and for UI-01/03 are generated by pytest from the live app and byte-compared in CI.
3. Every UI test uses two-fixture differentials scoped with `within(row)` — never single-fixture existence checks.
4. New pages live in `apps/ui/src/pages/*.tsx`, each with an `h1` and focusable scroll regions (do not add to the F1–F4 backlog).
5. No new persisted fields on `MetaPlugin`/`PluginInstallation`; `PluginDetail` already composes what the page needs.
6. uuid-suffixed ids in every new pytest fixture.
