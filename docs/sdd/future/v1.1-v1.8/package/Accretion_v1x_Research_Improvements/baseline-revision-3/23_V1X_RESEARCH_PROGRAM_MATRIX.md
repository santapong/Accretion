## 2. Cross-study invariants

- Freeze the estimand, task population, candidates, verifier, acquisition rule, cost ledger, stopping rule and analysis code before adaptive observations.
- Use project/domain/time separation appropriate to the claim. The final hidden set is accessed once.
- Count non-PASS outcomes at the frozen TTVS horizon and retain them in the success denominator.
- Keep platform readiness, research closure and artifact promotion as separate decisions.
- Preserve negative, contradictory and inconclusive evidence.
- Do not use later-release research to bypass an earlier operational gate.

## 3. Research priority

1. v1.1 trace inventory and verifier qualification.
2. v1.1 offline replay of uniform and adaptive acquisition.

4. v1.1 common holdout and selection-regret report.
5. Reassess whether v1.2 is still the highest-value next release; later SDDs remain designs, not commitments to run.
